## English Version

### Project Overview
This project is a high-performance developer portfolio and cinematic case study showcase. It exhibits complex relational architectures, low-level hybrid applications, and high-fidelity graphics. Featuring elegant glassmorphism effects, viewport-optimized animations, fluid CSS clamp typography, and smart navigation controls that automatically retract inside project pages for a premium, distraction-free reading experience.

### Core Architecture
* Frontend Framework: Next.js with React and Tailwind CSS.
* State & Animations: Framer Motion for high-fidelity animations.
* Responsive Typography: Built using fluid CSS clamp values to auto-scale perfectly from mobile viewports to ultra-wide displays.
* Navigation System: Custom interactive navigation dock with automatic page context recognition.
* Themes: Dynamic dark and light theme integration based on system preferences.

### Installation and Setup
Ensure you have Node.js v18+ installed on your system.

1. Clone the repository:
   ```bash
   git clone [YOUR_REPOSITORY_URL]
   cd [YOUR_PROJECT_DIRECTORY]
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```
   Open your browser and navigate to: http://localhost:3000

4. Build for production:
   ```bash
   npm run build
   ```

## النسخة العربية

### نظرة عامة
هذا المشروع هو منصة سيرة ذاتية ومحفظة أعمال هندسية متقدمة مصممة خصيصاً لإبراز الأنظمة المعقدة والتكاملات البرمجية. تتميز المنصة بتصميم زجاجي عصري، خطوط ديناميكية ذكية تتجاوب تلقائياً مع كافة مقاسات الشاشات، ونظام تنقل ديناميكي يختفي تلقائياً داخل دراسات الحالات لضمان تصفح مريح وخالٍ من المشتتات.

### البنية الأساسية
* إطار العمل: Next.js مع React و Tailwind CSS.
* الحركات والتفاعل: Framer Motion للحركات والتأثيرات الانتقالية السلسة.
* الخطوط والتجاوب: استخدام خاصية CSS clamp لحساب أحجام الخطوط ديناميكياً لتناسب شاشات الهواتف والأجهزة المكتبية العملاقة بدقة متناهية.
* نظام التنقل: شريط تنقل سفلي تفاعلي ذكي يتعرف على سياق الصفحة تلقائياً.
* الأنماط: تكامل ديناميكي للوضع المظلم والمضيء يعتمد على تفضيلات نظام تشغيل المستخدم.

تأكد من تثبيت إصدار Node.js v18+ على جهازك.

1. نسخ مستودع المشروع:
   ```bash
   git clone [رابط_مستودع_الكود_الخاص_بك]
   cd [اسم_مجلد_المشروع]
   ```

2. تثبيت الحزم البرمجية:
   ```bash

   ```

   ```bash

   ```
   افتح المتصفح على الرابط: http://localhost:3000

4. بناء النسخة الإنتاجية:
   ```bash

   ```
